# Customer-Shopping-Behaviour-analysis
Customer Shopping Behaviour Analysis

1. Project Overview

This project focuses on analyzing customer shopping behaviour to understand purchasing patterns and customer preferences. The analysis helps identify how different customer groups purchase products based on age, gender, product category, location, and product color.

2. Problem Statement

Understanding customer shopping behaviour is important for businesses to improve customer satisfaction and make better business decisions.

This project aims to analyze customer purchase data and identify patterns across different customer segments.

3. Project Objectives

- To analyze purchases across different age groups.
- To understand purchasing patterns based on gender.
- To identify the most purchased product categories.
- To analyze purchases across different locations.
- To identify the most preferred product colors.
- To present the findings through an interactive dashboard.

4. Dataset Description

The project uses a Customer Shopping Behaviour dataset containing customer and purchase-related information.

The dataset includes fields such as:

- Customer ID
- Age
- Gender
- Category
- Location
- Color

5. Tools and Technologies Used

- Tableau Public – Data Visualization and Dashboard Creation
- Microsoft Excel – Data Understanding and Preparation
- GitHub – Project Documentation and Portfolio

6. Data Analysis

The dataset was analyzed using Tableau to create five visualizations:

1. Age-wise Purchase Count
2. Gender-wise Purchase Count
3. Category-wise Purchase Count
4. Location-wise Purchase Count
5. Color-wise Purchase Count

These visualizations help understand customer purchasing patterns across different dimensions.

7. Key Findings

The analysis focuses on identifying:

- Which age groups have higher purchase counts.
- How purchasing patterns differ by gender.
- Which product categories receive more purchases.
- Which locations have higher purchase counts.
- Which product colors are more popular.

Actual findings and values will be added based on the dashboard results.
